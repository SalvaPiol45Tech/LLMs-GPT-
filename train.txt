# ARTIFICIAL INTELLIGENCE FOUNDATIONS

Machine learning is fundamentally about finding patterns in data. When we have examples of input-output pairs, we want to learn a function that maps inputs to outputs. The challenge is that we don't know the true function; we only have finite samples. Machine learning algorithms find approximate functions that generalize well to new examples.

Supervised learning requires labeled training data where each input is paired with the correct output. Classification tasks assign inputs to predefined categories, while regression tasks predict continuous values. The learning algorithm adjusts model parameters to minimize errors on training data while maintaining good generalization to unseen test data.

The concept of generalization is central to machine learning. A model that memorizes training data but fails on test data has poor generalization. Conversely, models that learn general patterns transfer well to new data. The generalization error depends on model complexity, training data size, and the inherent difficulty of the underlying problem.

Overfitting occurs when models become too complex and memorize training data including noise. This typically happens with large models trained on small datasets. Regularization techniques like L1 and L2 regularization, dropout, and early stopping prevent overfitting by constraining model complexity.

Underfitting occurs when models are too simple to capture important patterns in data. Simple models may achieve low training accuracy if the underlying function is complex. The bias-variance tradeoff formulates this: models with low bias have high variance and vice versa. Optimal models balance these competing concerns.

Features are the input variables provided to machine learning models. Feature engineering involves transforming raw data into features that machine learning algorithms can effectively use. Good features are informative about targets and efficient to compute. Modern deep learning methods often learn features automatically rather than requiring manual engineering.

Train-test splits divide data into training and test sets. The training set trains the model while the test set evaluates generalization. Proper separation prevents data leakage where test information influences training. Cross-validation improves estimation by using multiple train-test splits.

# DEEP NEURAL NETWORKS

Neural networks are computational models inspired by biological neural systems. They consist of layers of interconnected units that transform inputs through mathematical operations. Deep networks with many layers can learn hierarchical representations.

A neuron computes a weighted sum of inputs plus a bias term, then applies an activation function. The activation function introduces nonlinearity enabling complex function approximation. Without nonlinearity, stacking layers would be equivalent to a single linear transformation.

The ReLU activation function computes max(0, x), outputting zero for negative inputs and the input for positive values. ReLU is computationally efficient and enables effective training of deep networks. Variant activations like Leaky ReLU and GELU provide modifications addressing various issues.

The sigmoid activation outputs values between 0 and 1, mapping any input to this range. Historically important, sigmoid is less commonly used in hidden layers now due to vanishing gradient problems. It remains useful for binary classification output layers.

Tanh activation maps inputs to [-1, 1] range, centered at zero. Like sigmoid, tanh can suffer from vanishing gradients. However, centering at zero often provides training benefits compared to sigmoid.

Network architecture defines how layers connect. Feedforward networks process inputs through successive layers without feedback. Residual connections skip layers, enabling deeper networks. Convolutional, recurrent, and attention-based architectures provide structure for specific data types.

Depth refers to the number of layers. Deeper networks can learn more abstract representations but are harder to train. Skip connections enable training of very deep networks by enabling gradient flow.

Width refers to layer sizes. Wider layers have more parameters and capacity. Very wide networks can be overtrained on small datasets. Optimal width depends on data size and complexity.

Backpropagation computes gradients for all parameters efficiently using the chain rule. Starting from output layer loss, it propagates gradients backward through layers. Each layer computes how upstream loss changes with respect to its parameters and inputs.

The gradient tells us direction to step in parameter space to reduce loss. Large gradients indicate steep loss surface, suggesting large steps are beneficial. Small gradients indicate flat regions where careful stepping is needed.

Vanishing gradients occur when gradients through deep networks become extremely small. Early layers receive tiny gradients slowing learning. ReLU activation and skip connections mitigate this problem.

Exploding gradients occur when gradients become very large. This causes unstable training with parameters diverging. Gradient clipping limits gradient magnitude preventing explosion.

# TRAINING NEURAL NETWORKS

Gradient descent optimizes parameters by stepping in gradient direction. Learning rate controls step size. Too large learning rates overshoot optimal values; too small learning rates converge slowly.

Mini-batch gradient descent estimates gradients from small data batches. This balances computational efficiency with gradient accuracy. Batch size is a key hyperparameter affecting training dynamics and generalization.

Momentum accelerates learning by accumulating gradient direction through time. This helps traverse flat regions and can skip over small local minima. Nesterov momentum looks ahead, providing improved acceleration.

Adaptive learning rate methods adjust per-parameter learning rates based on gradient history. Adam combines momentum with adaptive learning rates, working well in practice. Other adaptive methods include RMSprop and AdaGrad.

Learning rate scheduling adjusts learning rate during training. Starting with larger learning rates enables fast progress. Reducing learning rates later enables fine-tuning. Schedules like cosine annealing and step decay are common.

Batch normalization standardizes layer inputs to zero mean and unit variance. This stabilizes training and enables higher learning rates. Batch norm acts as regularizer reducing overfitting. It's now standard in most modern architectures.

Layer normalization normalizes across features for each example independently. Unlike batch norm, it doesn't depend on batch statistics. Layer norm is essential for Transformers and some other architectures.

Dropout randomly disables neurons during training with some probability. This prevents neurons from co-adapting to specific training examples. Dropout acts as ensemble method where different subnetworks train simultaneously.

Early stopping stops training when validation performance plateaus. This prevents overfitting and reduces training time. Early stopping is essential for model selection and generalization.

Weight initialization affects training speed and final performance. Random initialization prevents symmetry where all weights are identical. Initialization scales should account for network width.

# CONVOLUTIONAL NEURAL NETWORKS

Convolutional layers apply learned filters to input regions. Each filter detects different local patterns like edges or textures. Sharing weights across positions dramatically reduces parameters compared to fully connected layers.

Convolution operations compute dot products between filters and image patches. Multiple filters create feature maps capturing different patterns. Biases add per-filter constants enabling flexible learned thresholds.

Padding extends images around borders preventing size reduction. Zero padding is most common. Proper padding enables controlling output size independent of input size.

Stride controls how filter positions move across input. Stride 1 moves one pixel per operation. Larger strides reduce output size but may miss patterns. Stride selection involves tradeoffs between computation and resolution.

Pooling reduces spatial dimensions by aggregating regions. Max pooling takes maximum in regions, preserving important values. Average pooling averages regions, smoothing feature maps. Pooling reduces parameters and computation while capturing key information.

Feature hierarchies emerge in deep CNNs. Early layers detect simple features like edges and colors. Intermediate layers combine features into textures and parts. Deeper layers recognize complex objects and concepts.

Receptive field is the input region affecting a particular output unit. Deeper units have larger receptive fields seeing more context. Understanding receptive fields helps designing architectures for different applications.

Skip connections connect layers across multiple levels. ResNets enable training of very deep networks through skip connections. Skip connections enable gradient flow through many layers.

Residual learning formulates learning as f(x) + x rather than f(x). This residual formulation helps training by making incremental changes easier than learning full mappings. Skip connections implement residual learning efficiently.

Bottleneck blocks use 1x1 convolutions to reduce and then expand channels. This reduces computation while maintaining expressiveness. Bottleneck blocks enable efficient deep networks like ResNet-50.

Depthwise separable convolutions factorize standard convolutions into depthwise and pointwise components. This reduces computation dramatically while maintaining capacity. Efficient architectures like MobileNets leverage this technique.

# RECURRENT NEURAL NETWORKS

Recurrent networks maintain hidden state that accumulates information over time. At each step, the hidden state combines previous state with current input. This enables processing variable-length sequences and capturing temporal dependencies.

The hidden state acts as network memory containing information about previous inputs. Longer sequences require remembering information over longer time scales. Adequate hidden state size is essential for capturing long-term dependencies.

Unrolling recurrent networks over time reveals how they process sequences. Applying backpropagation through time computes gradients through all time steps. This reveals the vanishing and exploding gradient problems affecting RNNs.

Vanishing gradients in RNNs cause gradients to decay exponentially through time. Early time steps receive negligible gradients preventing learning of long-term dependencies. This limits RNN effectiveness for long sequences.

Long Short-Term Memory networks address vanishing gradients through gating mechanisms. Forget gates control which information is discarded. Input gates control which new information is added. Output gates control which information influences outputs.

LSTM cells maintain cell state separate from hidden state. Cell state enables information to flow unchanged through many steps. Gating mechanisms update cell state in controlled ways.

Gated Recurrent Units simplify LSTMs with fewer gates. Reset gates control influence of previous hidden state. Update gates control how much of previous state and new information to keep. GRUs are simpler than LSTMs but often perform similarly.

Bidirectional RNNs process sequences both forward and backward. Forward RNN processes left to right; backward processes right to left. Concatenating representations enables using full context for each position. Bidirectional processing improves performance on many tasks.

Sequence-to-sequence models use encoder RNNs to process inputs and decoder RNNs to generate outputs. Encoder produces fixed-size context vector. Decoder generates outputs conditioned on this context. This architecture enables variable-length input-to-output mapping.

Attention mechanisms allow decoders to access all encoder states rather than just final state. At each decoding step, attention weights determine how much each encoder state contributes. Attention enables focusing on relevant parts of inputs.

Beam search generates high-probability sequences by exploring promising partial sequences. Keeping top-k partial sequences at each step reduces computation compared to exhaustive search. Beam search provides good performance-quality tradeoffs in sequence generation.

# TRANSFORMERS AND ATTENTION

Self-attention computes similarity between all positions and uses similarities as weights. Each position can attend to all others, enabling long-range interactions. Multiple attention heads capture different types of relationships.

Queries, keys, and values parameterize attention. Queries represent "what we're looking for," keys represent "what we're offering," and values represent "what we return." Attention weights compute compatibility between queries and keys.

Scaled dot-product attention computes attention weights as softmax of scaled query-key dot products. Scaling by key dimension normalizes variance. Softmax converts scores to probability distribution.

Multi-head attention applies attention multiple times in different subspaces. Different heads capture different relationships and dependencies. Multi-head attention is more expressive than single-head attention.

Position embeddings inject information about token position into representations. Absolute position embeddings assign unique embeddings to positions. Relative position embeddings encode relative distances between positions.

Positional encodings use sinusoidal functions to represent positions. Different frequencies capture different scales of positional information. Sinusoidal encodings enable extrapolation to longer sequences.

Transformer blocks combine self-attention with feed-forward networks. Self-attention captures dependencies between positions. Feed-forward networks apply per-position transformations. Normalization and residual connections stabilize training.

Encoder-only Transformers process inputs without generating sequences. BERT-style models use masked language modeling training objective. These models excel at understanding and analyzing text.

Decoder-only Transformers generate sequences autoregressively. GPT-style models predict next tokens given previous tokens. These models excel at language generation tasks.

Encoder-decoder Transformers process inputs with encoders and generate outputs with decoders. Attention from decoders to encoder enables using input information. These models excel at translation, summarization, and other sequence-to-sequence tasks.

Causal masking prevents decoder positions from attending to future positions. This ensures autoregressive generation respects causality. Causal attention is essential for autoregressive language models.

# OPTIMIZATION AND REGULARIZATION

Learning rate is the most important hyperparameter. Too high learning rates cause divergence; too low causes slow convergence. Learning rate schedules adjust rates during training for better convergence.

Momentum accumulates gradients through time providing acceleration. Heavy ball analogy: momentum acts like a ball rolling downhill. Nesterov momentum looks ahead providing faster convergence than standard momentum.

Adam combines advantages of momentum methods and adaptive learning rates. It maintains per-parameter learning rates based on first and second moment estimates. Adam works well in practice though theoretical understanding remains incomplete.

L1 regularization adds sum of absolute weights to loss. This encourages sparsity making many weights exactly zero. Sparse models have fewer parameters and can be more interpretable.

L2 regularization adds sum of squared weights to loss. This discourages large weights but rarely makes them zero. L2 regularization is more common than L1 for neural networks.

Elastic net combines L1 and L2 regularization. This provides benefits of both sparsity and weight decay. Elastic net is particularly useful when both effects are desired.

Dropout randomly zeros activations during training. Each unit has probability p of being dropped. Dropout prevents co-adaptation and acts as ensemble of thinned networks.

Data augmentation artificially expands training data through transformations. Image augmentation includes rotation, translation, scaling, and brightness changes. Augmentation improves generalization by showing variations of data.

Early stopping monitors validation performance stopping when it plateaus. This prevents overfitting while avoiding unnecessary computation. Early stopping requires separate validation set.

Gradient clipping bounds gradient magnitude preventing exploding gradients. If gradient norm exceeds threshold, scale down to threshold. Gradient clipping stabilizes training especially in RNNs.

Weight decay adds regularization term to optimization. Weight decay encourages smaller weights reducing model complexity. Weight decay is equivalent to L2 regularization in some formulations.

# REINFORCEMENT LEARNING BASICS

The reinforcement learning problem involves an agent interacting with an environment. Agents observe states, take actions, and receive rewards. The goal is maximizing cumulative reward over episodes.

Markov decision processes formalize RL with states, actions, transition probabilities, and rewards. The Markov property states that future depends only on current state, not history. MDPs provide mathematical framework for RL.

Value functions estimate expected cumulative reward from states. State value functions V(s) give value of states. Action value functions Q(s,a) give value of state-action pairs.

The Bellman equation relates values at different states. Optimal value functions satisfy Bellman optimality equations. Value iteration and policy iteration compute optimal values using Bellman equations.

Policy functions map states to actions. Stochastic policies output action probabilities. Deterministic policies output single actions. Optimal policies maximize expected cumulative reward.

Exploration-exploitation tradeoff involves choosing between trying new actions and exploiting known rewards. Epsilon-greedy exploration takes random actions occasionally. Upper confidence bounds balance exploration strategically.

Q-learning learns action values from experience without models. Off-policy learning enables learning from suboptimal policies. Temporal difference updates enable incremental learning.

Deep Q-networks combine Q-learning with neural networks. Networks approximate Q functions avoiding explicit tables. Experience replay stabilizes training by breaking correlations.

Policy gradient methods optimize policies directly. REINFORCE computes policy gradients from trajectory rewards. Actor-critic methods use value functions to reduce variance.

Actor-critic methods learn both policy and value function networks. Policies generate actions while value functions estimate returns. Critic reduces variance enabling faster learning.
